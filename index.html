Paso 2 - Ir a configuración WiFi

Seleccione Net → WLAN → WLAN Parameter Configuration

Paso 3 - Cambiar nombre y contraseña

📶 SSID = Nombre de la red WiFi
🔐 WPA Pre-Shared Key = Contraseña WiFi

Paso 4 - Guardar cambios

Toque el botón Apply para guardar.
